# Interactive Notes - Frontend

Клиентская часть приложения "Сервис для создания интерактивных конспектов".
Реализована на React с Ant Design и JWT-аутентификации.

## Технологии

- **React** — библиотека для построения пользовательских интерфейсов
- **Vite** — сборщик и инструмент разработки
- **Ant Design** — UI-библиотека компонентов
- **React Router** — маршрутизация
- **Axios** — HTTP-клиент для работы с API

## Функциональность

- **Аутентификация**: регистрация и вход с JWT-токенами
- **Управление конспектами**: создание, просмотр, редактирование, удаление
- **Ролевая модель**:
    - Владелец — полный доступ
    - Редактор — может изменять содержимое
    - Зритель — только просмотр
- **Управление соавторами**: добавление, изменение ролей, удаление
- **Редактор конспектов**: создание разделов и блоков (текст/код)

## Установка и запуск

### Требования

- Node.js 20.19+ или 22.12+
- npm

### Локальный запуск

```bash
# Клонирование репозитория
git clone git@github.com:v-tempe/interactive-notes-server.git
cd interactive-notes-frontend

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```
Приложение будет доступно по адресу: http://localhost:5173

### Сборка для продакшена
npm run build


## Docker

### Сборка образа
docker build -t interactive-notes-frontend .

### Запуск контейнера
docker run -p 8080:80 interactive-notes-frontend

Приложение будет доступно по адресу: http://localhost:8080

### Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| VITE_API_URL | URL бэкенд-API | http://127.0.0.1:8000/api |

Для продакшена задайте переменную при сборке.

## Роутинг

| Путь | Описание | Доступ |
|------|----------|--------|
| /login | Страница входа | Публичный |
| /register | Страница регистрации | Публичный |
| / | Дашборд со списком конспектов | Авторизованный |
| /notebook/:id | Просмотр конспекта | Авторизованный |
| /notebook/:id/edit | Редактирование конспекта | Владелец/Редактор |

## Взаимодействие с бэкендом

Фронтенд работает с REST API бэкенда. Основные эндпоинты:

- POST /api/auth/register/ — регистрация
- POST /api/auth/token/ — получение JWT
- GET /api/notebooks/ — список конспектов
- POST /api/notebooks/ — создание конспекта
- GET/PUT/PATCH/DELETE /api/notebooks/{id}/ — работа с конспектами
- GET/POST /api/notebooks/{id}/collaborators/ — управление соавторами
- GET/PUT/PATCH/DELETE /api/notebooks/{id}/collaborators/{id}/ — управление соавторами

Ссылка на репозиторий бэкенда: https://github.com/v-tempe/interactive-notes-server
